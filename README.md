# شاشة زمان

أرشيف للسينما المصرية حتى عام 2000: آلة زمن تتنقّل بين العقود، وأرشيف للأفلام، ولعبة «خمّن الفيلم».

## هيكل بيانات الفيلم

كل فيلم سجلّ واحد، والسجلّ نفسه تستخدمه أقسام الموقع كلها:

```json
{
  "id": "al-ard",
  "title": "الأرض",
  "title_en": "The Land",
  "year": 1970,
  "director": "يوسف شاهين",
  "cast": ["محمود المليجي", "عزت العلايلي", "نجوى إبراهيم"],
  "genre": ["دراما"],
  "based_on": "رواية عبد الرحمن الشرقاوي",
  "summary": "وصف قصير",
  "poster": { "status": "generated", "url": null, "credit": null },
  "clues": ["السنة: 1970", "المخرج: يوسف شاهين", "عن رواية لعبد الرحمن الشرقاوي", "بطولة محمود المليجي"],
  "wikidata": "Q…"
}
```

- `poster.status`: إما `commons` (صورة من ويكيميديا كومنز مع ذكر صاحبها)، أو `link` (رابط خارجي للأفيش)، أو `generated` (أفيش يولّده الموقع بالكود).
- `clues`: تلميحات «خمّن الفيلم»، من الأصعب إلى الأسهل.
- `wikidata`: معرّف الفيلم في ويكي بيانات.
