# شاشة زمان

أرشيف للسينما المصرية حتى عام 2000: آلة زمن تتنقّل بين العقود، وأرشيف للأفلام، ولعبة «خمّن الفيلم».

## بنية المشروع

- `index.html`: الموقع كله (آلة الزمن، البحث، صفحة الفيلم).
- `data/films.json`: بيانات الأفلام، سجلّ لكل فيلم.
- `films/<id>.md`: مقالة صفحة الفيلم (نقد، قصة، كواليس…). اسم الملف هو `id` الفيلم نفسه.

## كتابة مقالة لفيلم

أنشئ ملفًا في مجلد `films` باسم الفيلم، مثل `films/al-karnak-1975.md`، واكتب فيه بصيغة Markdown:

```markdown
## نقد

فقرة عادية. ويمكن استخدام **خط عريض** و*مائل* و[رابط](https://example.com).

> اقتباس يظهر بشكل مميّز.

## المصادر

- [اسم المصدر](https://example.com)
```

تظهر المقالة تلقائيًا في صفحة الفيلم، ورابط الصفحة: `cimaeg.github.io/#film-al-karnak-1975`.
الفيلم الذي ليس له ملف تظهر في صفحته عبارة «لم تُكتب عن هذا الفيلم مقالة بعد».

## هيكل بيانات الفيلم

كل فيلم سجلّ واحد، والسجلّ نفسه تستخدمه أقسام الموقع كلها:

```json
{
  "id": "al-ard-1970",
  "title": "الأرض",
  "year": 1970,
  "director": "يوسف شاهين",
  "cast": ["محمود المليجي", "عزت العلايلي", "نجوى إبراهيم"],
  "genre": ["دراما"],
  "based_on": "رواية عبد الرحمن الشرقاوي",
  "writer": "عن رواية عبد الرحمن الشرقاوي، سيناريو وحوار حسن فؤاد",
  "producer": "المؤسسة المصرية العامة للسينما",
  "duration": "نحو ١٣٠ دقيقة",
  "premiere": "",
  "summary": "وصف قصير يظهر أعلى صفحة الفيلم",
  "poster": { "status": "generated", "url": null, "credit": null },
  "ratings": {
    "imdb": { "id": "tt0064038", "score": 8.0, "votes": 2800 },
    "elcinema": { "id": "1010126", "score": 9.1 }
  },
  "clues": ["السنة: 1970", "المخرج: يوسف شاهين", "عن رواية لعبد الرحمن الشرقاوي", "بطولة محمود المليجي"],
  "wikidata": "Q…"
}
```

- `poster.status`: إما `commons` (صورة من ويكيميديا كومنز مع ذكر صاحبها)، أو `link` (رابط خارجي للأفيش)، أو `generated` (أفيش يولّده الموقع بالكود).
- `clues`: تلميحات «خمّن الفيلم»، من الأصعب إلى الأسهل.
- `wikidata`: معرّف الفيلم في ويكي بيانات.
- `ratings`: تقييمات الجمهور. `id` هو رقم الفيلم في رابط الموقع (imdb.com/title/**tt0064038** و elcinema.com/work/**1010126**). أي موقع بلا تقييم يُحذف من السجلّ فلا يظهر.
